# Meridian Malvan website

A responsive hotel website built with Next.js App Router, TypeScript, and Tailwind CSS v4. Includes SEO metadata, sitemap and robots routes, Hotel structured data, informational pages, and a server-validated enquiry form.

## Run locally

1. Run npm install.
2. Copy .env.example to .env.local.
3. Run npm run dev.

Configure NEXT_PUBLIC_SITE_URL, BOOKING_INBOX, RESEND_API_KEY, and RESEND_FROM to enable email delivery. Replace placeholder property details and illustrative coastal imagery with verified information before launch.

The form submits an enquiry only. It does not check live inventory, accept payment, or create a confirmed reservation.
